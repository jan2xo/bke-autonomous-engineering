# BKE Autonomous Engineering — Agent Bootstrap

This file is intentionally small. It is a recovery compass, not the full operating contract.

1. Treat the adopted BKE Engineering Standard as engineering doctrine.
2. Treat this repository as the reusable autonomous-execution governance source.
3. For a declared intent, resolve only the instruction modules named by that intent.
4. Prefer the latest exact-head Intent CI capsule before opening raw logs.
5. Escalate evidence progressively: capsule -> failing step/log slice -> full logs/artifacts only when needed.
6. Never weaken required verification, security, production, or human-authorization boundaries to save context or CI cost.
7. Reconstruct consequential state from Git and repository evidence, not conversational memory.

When autonomous operating context is materially incomplete, read `AUTONOMOUS-CORE-INSTRUCTION.md` and the relevant modules under `instructions/`.
